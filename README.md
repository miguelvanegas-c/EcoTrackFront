# EcoTrack - Dashboard de Emisiones

## Cómo correrlo
1. Crea un proyecto en https://supabase.com y ejecuta `supabase/setup.sql` en el SQL Editor.
2. Copia `.env.example` a `.env` y pon tu URL y anon key (Project Settings > API).
3. En la terminal:
   ```
   npm install
   npm run dev
   ```
4. Abre http://localhost:5173
